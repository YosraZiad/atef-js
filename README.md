# My Next.js App

مشروع Next.js حديث مع shadcn/ui والوضع الليلي ودعم تعدد اللغات.

## الميزات المُنفذة

### ✅ المكونات الأساسية
- **Next.js 15** - أحدث إصدار من Next.js
- **TypeScript** - دعم كامل لـ TypeScript
- **Tailwind CSS** - للتصميم والتنسيق
- **shadcn/ui** - مكتبة مكونات UI حديثة

### ✅ شريط التنقل
- **Sidebar-07** - شريط تنقل جانبي متقدم من shadcn/ui
- تصميم قابل للطي والتوسع
- أيقونات وقوائم فرعية
- تصميم متجاوب

### ✅ الوضع الليلي والنهاري
- **next-themes** - مكتبة إدارة الثيمات
- تبديل سلس بين الوضع الليلي والنهاري
- حفظ تفضيلات المستخدم
- دعم وضع النظام التلقائي

### ✅ تعدد اللغات (i18n)
- **next-intl** - مكتبة تعدد اللغات
- دعم اللغة العربية والإنجليزية
- ترجمة كاملة لواجهة المستخدم
- دعم اتجاه النص (RTL/LTR)

## بنية المشروع

```
src/
├── app/
│   ├── [locale]/           # صفحات متعددة اللغات
│   │   ├── dashboard/      # صفحة لوحة التحكم
│   │   ├── layout.tsx      # تخطيط اللغات
│   │   └── page.tsx        # الصفحة الرئيسية
│   ├── layout.tsx          # التخطيط الرئيسي
│   ├── not-found.tsx       # صفحة عدم الوجود
│   └── page.tsx            # إعادة توجيه
├── components/
│   ├── ui/                 # مكونات shadcn/ui
│   ├── app-sidebar.tsx     # شريط التنقل الرئيسي
│   ├── nav-*.tsx           # مكونات التنقل
│   ├── theme-provider.tsx  # مزود الثيمات
│   └── theme-toggle.tsx    # مبدل الوضع
├── lib/
│   └── utils.ts            # أدوات مساعدة
├── hooks/
│   └── use-mobile.ts       # هوك للجوال
└── i18n.ts                 # تكوين التعدد اللغوي
```

## ملفات الترجمة


## كيفية التشغيل

### 1. تثبيت التبعيات
```bash
npm install
```

### 2. تشغيل الخادم المحلي
```bash
npm run dev
```

### 3. فتح المتصفح
انتقل إلى: `http://localhost:3000`

## الروابط المتاحة

- `/` - الصفحة الرئيسية (إعادة توجيه إلى /en)
- `/en` - الصفحة الرئيسية بالإنجليزية
- `/ar` - الصفحة الرئيسية بالعربية
- `/en/dashboard` - لوحة التحكم بالإنجليزية
- `/ar/dashboard` - لوحة التحكم بالعربية

## الميزات التفاعلية

### تبديل الوضع الليلي/النهاري
- انقر على أيقونة المستخدم في شريط التنقل
- اختر "Dark Mode" أو "Light Mode"

### تبديل اللغة
- انقر على أيقونة المستخدم في شريط التنقل
- اختر "العربية" أو "English"
